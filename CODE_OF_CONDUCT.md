# Code of Conduct

This Code of Conduct applies to everyone participating in the StreamArena
repository and any associated project spaces (issues, pull requests, code
review, internal chat channels) maintained by Aussi-Nexus Group.

## Our standard

Be respectful. Disagreement about code, design, or priorities is normal
and welcome — personal attacks, harassment, discriminatory language or
jokes, and unwelcome sexual attention or comments are not, regardless of
who they're directed at.

Examples of unacceptable behavior include: harassment, insulting or
derogatory comments, public or private harassment, publishing others'
private information without consent, and any other conduct which could
reasonably be considered inappropriate in a professional setting.

## Scope

This applies within all project spaces (this repository and its issues,
PRs, and discussions) and in any other context when representing the
project or its community.
